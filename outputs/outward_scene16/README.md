# Outward hero cycle with scene-lit 16×16 tiles

The opening Spider-Man portrait reveals a large Iron Man helmet, then Captain America, then the original Spider-Man as the camera pulls out. Every parent is made from 256 separately seeded native SDXL generations. The recursive image replaces one generated cell on each board at rendering time. Native board dimensions are 16,384×16,384.

The first 16×16 version used a pale studio-lit Iron Man. Following the user's visual review, the final uses the already generated dark blue and crimson industrial Iron Man portrait (candidate 3, seed 9108203). The Spider-Man opening and Captain America candidate 2 are retained. The eight target candidate samples and all prompts and seeds are listed under outputs/outward_palette16. View the two 16×16 versions together in scene_comparison.jpg.

## Generation

The new rule generates a hero interacting with a setting such as a railing, a workshop or a brick passage. The target cell chooses the lighting and compatible setting from its RGB means. The negative prompt describes a white studio backdrop and an isolated faded cutout. For low-detail target cells, the initial latent uses a weaker parent signal and later guidance constrains mostly the cell's mean color. The SDXL trajectory can then develop its own shadows, physical surfaces, and figure/background separation. In high-contrast cells the original bright-boundary constraint is weighted by the target's luminance variation. The full code, prompts and exact threshold definitions are in scene.py.

The entire Iron Man parent is resampled for its new target. In the other two parents the rule activates if the target cell has luminance standard deviation below 0.075, and mean luminance above 0.42 or mean-color channel range below 0.11. This test runs on a 16×16 thumbnail of the team's target crop and can be computed before generating any tiles. Cells outside the rule use the exact previously generated trajectory. All active cells use their original coordinate seeds, with one final trajectory per cell. The pilot images used in the completed board are identical to the corresponding full-run outputs.

## Paired background study

Sixteen deterministic positions span the target luminance distribution (four Spider-Man parent cells, eight Iron Man cells, four Captain America cells). Each comparison keeps the target, pixel coordinates and noise seed the same, including regenerating eight original-method control trajectories for the new Iron Man portrait. The study uses frozen CLIP scores for scene context and hero recognizability and 4×4 RGB mean absolute errors for macro color. Adoption criteria check scene gain and number of improving cells, with tolerances for small-scale identity and target-color drift. The eight-target composition shortlist and the decision to prefer the darker industrial portrait were visual decisions. No individual finished tile was hand-picked or repainted. The gallery pilot_comparison.jpg shows every paired example.

## Reproduction

The source ZIP includes both stages, bundled SDXL code, all tile generation manifests, the first generated Spider-Man intermediate, the original 8×8 diagnostic images, the 192 team-generated tile palette summaries, and the pinned model recipe. From the extracted project root use the creativegen package versions and pinned local checkpoints. For a rebuild from prompts and seeds:

```bash
export PYTHONPATH=. OMP_NUM_THREADS=2 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
python outputs/outward_palette16/opening.py
python outputs/outward_palette16/targets.py
python outputs/outward_palette16/generate_boards.py
python outputs/outward_palette16/render16.py
python outputs/outward_scene16/scene.py --pilot
python outputs/outward_scene16/pilot_review.py
python outputs/outward_scene16/scene.py
python outputs/outward_scene16/finish.py
```

The renderer chooses a junction on each board, resolves the recursive previews, writes three high-resolution JPEGs and a GIF, then verifies the decoded loop and 5.5-second stops. GIF boundary color is measured on the encoded stop frames. CLIP evaluates ordinary leaves at a common 44-pixel scale. The perimeter diagnostic counts light, low-chroma tiles among the 156 outer cells (three cells deep), on the actual finished boards. Reproduction provenance, sample counts, SHA-256 hashes, scene metrics, and peak PyTorch reserved GPU memory are included in the JSON reports.

The generator is the official SDXL base; CLIP is a score-only verifier. Target imagery and the previous visual references were generated by the team's own SDXL pipeline. The earlier README provides citations for the PhotoQuilt paper and code, Podell et al. SDXL, Radford et al. CLIP, and Diffusers. Code and prompt brainstorming used Codex.
