# Spider-Man → Iron Man → Captain America → Spider-Man

Run in the pinned creativegen environment from the PhotoQuilt project root. The official SDXL and CLIP revisions must be cached locally.

```bash
export PYTHONPATH=. OMP_NUM_THREADS=2 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
python outputs/spider_iron_captain/generate.py
python outputs/spider_iron_captain/render.py
```

Start from a seed-42 Spider-Man portrait generated by the SDXL base. Each board uses an 8×8 grid of 1024px PhotoQuilt tiles. Each generation uses a deterministic per-cell seed and twelve DDIM updates from t=836. At update six, score five candidate next steps by a 44px character CLIP margin minus twice the 4×4 luminance error relative to the parent crop. Use the winning update and finish sampling. The two forward destinations are chosen among the generated leaves by character and portrait verification with a parent-color penalty. Each selected tile supplies its unmodified latent to the next board. The last link is chosen by color and boundary fit to the opening overview. Solve the cyclic thumbnails until pixel-stable, then place the corresponding next overview verbatim into one square of each 8192px board. The GIF camera zooms inward three times. Physical cell equality and all decoded endpoints including the exact wrap are tested. generation.json records samples, prompts, seeds and branch decisions. report.json records the coordinates, timing, return costs and checksums. Source code and prompt brainstorming used Codex.

Method and dependencies: [PhotoQuilt paper](https://arxiv.org/abs/2606.30968v2), [official implementation](https://github.com/KooroshRH/PhotoQuilt), [SDXL](https://arxiv.org/abs/2307.01952), [SDXL base weights](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0), [DDIM](https://arxiv.org/abs/2010.02502), [CLIP](https://arxiv.org/abs/2103.00020), [CLIP weights](https://huggingface.co/openai/clip-vit-base-patch32), PyTorch, Hugging Face Diffusers and Transformers, NumPy and Pillow.
